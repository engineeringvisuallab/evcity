# HK-5c: SLIPS + C-D ROADS (2026-11-22; numbers docs/HK_CD_SLIPS.txt, data docs/hk_cd_slips.json). The result table is in docs/HK_LOOPS.md; this file only explains the method.
- Slip: left turn (left-hand traffic) before the crossing, from the C-D road to the cross road, drawn like the game's own 'slip' role (45 deg arc, straight, 45 deg arc, Rs min(110, S)). It is checked against the loop of the same quadrant: smallest slipSize S (steps of 10 m, 150 .. 400) with plan gap >= minGap 14 m, the 45 m at each end being the join zones (same rule as Validate.ts). Result for R80: S 350.
- C-D road: copied BY READING from PatternCD.ts cdLayout (same arithmetic and CD_DEFAULTS: separation 3, V50, lead-in / lead-out 60 m): offset = half width 22.1 + 3 + ramp half width 4.2 = 29.3 m, shift = 29.3 - 17.3 = 12.0 m, exit transition = max(decel(V, 50), 15 x shift), entry transition = max(accel(V, 50), 20 x shift), first gore at kerbLane + slipSize.
- Two offsets since the second run: arm side 29.3 m (M8 half 22.1, V100, kerb lane centre 17.3 ASSUMED = half - 3 - 1.825), link side 23.2 m (M6 half 16.0, V80, kerb lane centre 11.75). The north slip is checked against the NE loop, the south slip against the SE loop; west quadrants are x-mirrors. The C-D roads change offset in a reverse curve (R 93.7 m, 47.4 m) between the ring deck and the loop start.
- Weave = distance between the two gores on the same road: 2 x loop start distance on the C-D road, 2 x loop end distance on the ring.
- NOT run: game, tsc, build, Validate.ts on real Ramp objects.
