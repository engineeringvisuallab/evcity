# Charging points (ইলেকট্রিক চার্জ পয়েন্ট) — PLANNED, NOT BUILT

ইলেকট্রিক গাড়ি (রিকশা, EV Hypar, বাস, EV Bike) ব্যাটারি দিয়ে চলে। চার্জ পয়েন্ট এখনো **বানানো হয়নি** — শুধু জায়গাগুলোর লিস্ট এখানে রাখা আছে।

## এখন যা আছে
- ব্যাটারি/ফুয়েল ফুল থাকলে এক গাড়ি সাধারণ অবস্থায় **১০ / ১৫ / ২০ কিমি** চলে (`src/vehicles/Energy.ts`):
  রিকশা ১০, EV Hypar ১৫, EV Bike ১৫, বাস ২০।
- অবস্থা অনুযায়ী কমবেশি হয়: ৬০ কিমি/ঘণ্টার বেশি গতিতে বেশি খরচ, গাড়ি ভাঙা (hp কম) হলে বেশি খরচ, থ্রটল ছাড়লে কম খরচ।
- চার্জ শেষ হলে গাড়ি আর চলে না।
- আপাতত **ইভি ল্যাব পার্কিং লট** (`EVLAB_LOT`) একমাত্র চার্জ ডিপো: গাড়ি থামালে ~২৫ সেকেন্ডে ফুল চার্জ। 
  (`src/vehicles/FuelAreas.ts` → `chargeAreaAt`)
