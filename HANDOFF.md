# HANDOFF - EVCity (engineering-visual-city 0.9.0)

Anyone (developer or AI) should be able to continue from this file. Read it first, then the newest CHANGES_*.md.

## What it is
Browser open-world game, 100% Bangla UI/voice, to learn civil/mechanical/electrical engineering. 10x10 km map, roads, rail, city, vehicles, airport, port, farm, engineering zones, missions.
Stack: TypeScript, Vite, three.js 0.186, Rapier physics. Entry: `src/main.ts`, main class `src/core/Engine.ts`.

## Commands
- `npm ci` then `npm run typecheck` (`tsc --noEmit`), `npm run build`
- tests: `npx tsx scripts/<name>-test.ts` (97 scripts). Run few at a time: many are heavy (50-200 s).

## Rules for working on it
- Do not break existing systems. Finish with `npx tsc --noEmit` + the tests of the area you touched, write a `CHANGES_*.md`, update this file.
- `Engine.ts`, `bn.ts` etc. use CRLF line endings: keep CRLF when editing.
- Never overwrite `Engine.ts` from an old zip: merge hunks by hand (see merge notes).
- Deliver the FULL project zip (with `.git`) at the end of each finished phase.
